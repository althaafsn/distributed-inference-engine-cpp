# Portfolio materials

This folder turns the engineering work into material you can use in applications and interviews.

- [Case study](case-study.md) — a short problem, design, results, failure analysis, and limits.
- [Resume entry](resume-entry.md) — primary bullets, tailoring notes, evidence map, and a defensibility checklist.
- [Learning path](learning-path.md) — eight sessions from running the system to defending the design.
- [Demo script](demo-script.md) — a five-minute local demonstration.

Read the case study first. Use the learning path before you put the project on a resume. Do not claim production readiness, multi-AZ, TLS, or global admission; the measured limits are part of the story.
